# Классификация ландшафтов с использованием нейронных сетей

## Описание проекта

### Постановка задачи

Цель проекта - разработать нейросетевое решение для классификации различных
типов ландшафтов на основе их изображений, при этом отдельные части изображений
заменены не несущими информацию фрагментами. Данная задача имеет практическую
ценность, например, для различных беспилотных систем, от которых требуется
распознавать местность в условиях плохой видимости.

### Формат входных и выходных данных

Входные данные: RGB-изображение ландшафта (формат .JPG, размер изображения 256 х
256). Выходные данные: JSON-словарь, содержащий предсказание класса и
уверенность модели в своем предсказании.

### Метрики

В качестве метрики используется точность (accuracy). Выбор метрики обусловлен тем, что решаемая 
задача представляет собой обыкновенную задачу многоклассовой классификации, при этом
данные хорошо сбалансированы, поэтому точность вполне достоверно отражает качество обучаемых моделей. 

### Данные

В рамках задачи используется датасет ML Olympiad - Landscape Image Classification. 
Датасет содержит около 17000 изображений размерностью 256 х 256 х 3, разделенных на 6 классов
(buildings, forest, glacier, mountain, sea, street). От 20 до 60 процентов каждого изображения
случайным образом заменены не несущими информацию фрагментами.

Для версионирования данных используется DVC. Сами данные сохранены в публичном S3-бакете.

Ссылка на страницу Kaggle с данными: 
https://www.kaggle.com/competitions/ml-olympiad-landscape-image-classification/data

### Моделирование

В качестве бейзлайн-модели используется простейшая сверточная нейросеть, которая имеет архитектуру вида: 
сверточный слой - батч-нормализация - функция активации - макс-пулинг - линейный слой.
В качестве основной модели используется предобученная нейросеть EfficientNet B3. 

Обучение всех описанных ниже моделей осуществлялось с помощью библиотек PyTorch и PyTorch Lightning. 
Реализация нейросети EfficientNet B3 в PyTorch:
https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.efficientnet_b3.html

Параметры обучения моделей были одинаковыми:
- аугментации: отражение по горизонтали (horizontal flip);
- функция потерь: кросс-энтропия;
- оптимизатор: Adam.

### Setup

Алгоритм начала работы с проектом:

1. Клонировать репозиторий:
```
git clone https://github.com/Vladislav-IS/landscapes-classification.git
cd landscapes-classification
```

2. Установить виртуальное окружение:
```
pip install poetry
poetry install
```

3. Установить хуки pre-commit и запустить проверку: 
```
poetry run pre-commit install
poetry run pre-commit run -a
```

### Train

Алгоритм обучения моделей:

1. Активировать виртуальное окружение (если оно не было активировано):
```
poetry env activate
```

2. Запустить обучение модели:
```
poetry run python ./landscapes_classification/commands.py train
```

3. Запустить инференс обученной модели на тестовой части датасета:
```
poetry run python ./landscapes_classification/commands.py infer
```

Параметры обучения (архитектуру модели, пути сохранения логов и т.п.) можно задавать путем редактирования
YAML-файлов в конфигурации Hydra.
